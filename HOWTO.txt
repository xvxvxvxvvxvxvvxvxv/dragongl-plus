# --- Play alone -----------------------------------------------------------
# Just start the client and choose "Play Solo": it runs a private server
# for you in the background.
./dragongl-client            # OpenGL 3.3 (default)
./dragongl-client vk         # Vulkan 1.3

# --- Play with friends ----------------------------------------------------
# On the host:
./dragongl-server --password "anypassword"
# On every player's computer: start the client, choose "Join a Server",
# enter the host's address, port 8080 and the server password.
./dragongl-client 192.168.1.10 8080     # pre-fills the Join form
