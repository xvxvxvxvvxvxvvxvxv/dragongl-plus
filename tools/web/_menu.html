Workflow

1

Open the module

Each editor auto-loads its JSON database. If the page is opened via file://, just drop the file in — no server required.

2

Browse & inspect

Full-text search, colored category badges, distribution charts and sortable columns keep even thousands of entries under control.

3

Curate the content

Create, edit, duplicate or delete entries through validated forms. Unknown extra fields are always preserved, so the engine never loses data.

4

Commit the changes

Write straight back to the original file (Chrome/Edge, write permission) or export a ready-to-drop-in JSON copy. 2-space pretty format, always.

Recommended: serve the repository over HTTP

Opening the HTML files directly still works (manual file pick), but serving the repo unlocks automatic loading of all three databases from this menu: 

cd dragongl-dev
python3 -m http.server 8080
# then open  http://localhost:8080/tools/web/menu.html
